# 面配置

> 本页为机器翻译草稿，仅供参考，以英文版本为准：[English](../../Side-Config.md)。

所有基于 Neroland Core 构建的机器都共享同一种方式来控制其六个面如何与相邻方块交互。你可以逐面设定该面是**输入**资源、**输出**资源、连接**电力**，还是**禁用**——无论是 Nero 发电机、矿石处理机、氧气发生器，还是其他任何基于 Core 的机器，操作方式都相同。

本页面向玩家和整合包作者。开发者请阅读 [`../docs/SIDE-CONFIG.md`](../../../docs/SIDE-CONFIG.md)。

## 各个面

机器的各个面是相对于其朝向命名的——前、后、左、右、顶部、底部——因此即使你拆下机器并以不同朝向重新放置，你的设置依然正确。原来的输出面仍然是输出面。

每个面显示以下模式之一，并以颜色区分，便于一眼识别：

- **禁用**（灰色）——该面不进行任何连接。
- **输入**（蓝色）——相邻方块可以放入资源。
- **输出**（橙色）——相邻方块可以取出资源。
- **I/O**（绿色）——同一面既可输入也可输出。
- **推送**（黄色）——一种主动将资源喷送给相邻方块的输出，即使没有管道也可以。

## 通道

一台机器可以传输不止一种资源：**物品**、**流体**、**气体**和**电力**（能量）。每种资源都是独立的“通道”，有各自的逐面设置。只处理电力的发电机只显示一页；同时处理物品和电力的处理机则为每种资源各显示一个标签页。

## 使用面配置标签页

打开机器并点击面配置标签页。在展开的立方体上：

- **左键点击**某个面以循环切换其模式。
- **右键点击**某个面以快速禁用它。
- **中键点击**某个面以从调色板中选择特定模式。

你还会获得按通道划分的**自动输出**和**自动输入**开关（机器会自行从这些面推出／拉入资源，速度上限取决于整合包的传输速率设置）、一个将机器恢复为默认布局的**重置**按钮，以及将一台机器的布局应用到另一台同类机器的**复制／粘贴**功能。

## 配置器

一些内容模组（例如 Nerotech）会添加扳手式的**配置器**物品：在世界中右键点击机器的某个面即可循环切换该面的模式而无需打开界面，潜行右键点击可读取当前模式，还可以在机器之间复制／粘贴整个布局。

## 整合包作者

自动输出／自动输入的速度是 Core 配置中的一个服务器端数值 `sideConfigAutoTransferRate`——参见[配置](Configuration.md)。它可以通过 `/neroland config
reload` 热重载。将其设为 `0` 可完全禁用自动传输，改为依赖管道。

## 隐私

面配置随机器（方块）一起保存在世界中。它只记录机器如何传输资源——从不记录任何关于你的信息——因此不属于 Core 的玩家数据处理范围。参见[隐私与数据](Privacy-and-Data.md)。
