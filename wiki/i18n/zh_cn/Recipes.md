# 配方

> 本页为机器翻译草稿，仅供参考，以英文版本为准：[English](../../Recipes.md)。

Neroland Core 为其[材料](Materials.md)提供标准的压缩配方。每个配方都是 `data/nerolandcore/recipe/*.json` 下的普通数据，因此数据包可以自由替换、移除或添加配方。没有任何代码路径写死材料物品，配方引用的是 `c:`/`neroland:` 标签而非物品 ID。

## 压缩配方

| 材料 | 配方（双向） |
| --- | --- |
| Nero合金 | 方块 <-> 锭（9），锭 <-> 粒（9） |
| 星钢 | 方块 <-> 锭（9），锭 <-> 粒（9） |
| 虚空水晶 | 方块 <-> 宝石（9），宝石 <-> 碎片（9） |
| 等离子玻璃 | 玻璃方块 -> 玻璃板 |

虚空水晶沿着 方块 <-> 宝石 <-> 碎片 的链条压缩。

## 存储方块

Core 为其被动[存储方块](Machines-Power-and-Upgrades.md)提供合成配方——电池、流体储罐、气体储罐、物品存储器和垃圾桶。这些配方与方块此前附带的配方相同；与所有 Core 配方一样，它们引用 `#c:` 材料标签而非物品 ID，因此整合包可以替换金属或调整成本。（创造变体没有配方——它们仅限创造模式物品栏。）

| 方块 | 形状 | 材料 |
| --- | --- | --- |
| **电池** | 金属外壳包围一个红石与金属电芯 | `#c:ingots/*` 金属 + 红石 |
| **流体储罐** | 带玻璃窗的金属外壳 | `#c:ingots/*` 金属 + 玻璃 |
| **气体储罐** | 用金属密封的流体储罐 | `#c:ingots/*` 金属 + 一个流体储罐 |
| **物品存储器** | 金属框架包围一个箱子 | `#c:ingots/*` 金属 + 一个箱子 |
| **垃圾桶** | 一圈铁包围一株仙人掌 | `#c:ingots/iron` + 仙人掌 |

由于材料基于标签，具体使用哪种金属取决于整合包向 `#c:` 锭标签映射了什么；请引用标签，切勿引用具体的物品 ID。

## 覆盖与扩展

由于配方是普通数据且材料基于标签，整合包可以：

- 通过提供相同的配方 ID 来替换任何 Core 配方
- 移除某个配方
- 添加消耗 `c:` 或 `neroland:` 材料标签的新配方

请通过标签引用材料（例如 `c:ingots/nero_alloy`），切勿通过物品 ID。参见[标签与数据包](Tags-and-Datapacks.md)。

## 战利品表与挖掘

材料方块的战利品表位于 `data/nerolandcore/loot_table/blocks/*.json`。默认情况下，每个材料方块掉落其自身；整合包可以覆盖这些战利品表以实现精准采集或额外掉落。

挖掘标签列出了实心方块，因此工具要求可由整合包调整：

- `minecraft:mineable/pickaxe`
- `needs_iron_tool`
