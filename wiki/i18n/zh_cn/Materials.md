# 材料

> 本页为机器翻译草稿，仅供参考，以英文版本为准：[English](../../Materials.md)。

Neroland Core 为 Neroland 生态提供四种骨干材料。Core 提供物品、方块、标签和压缩配方——但**不提供矿石**。添加某种材料矿石的模组（例如 Nerospace 的行星矿石）会按标签冶炼成这些 Core 物品，因此所有模组共享同一套材料。

1.0.0 中附带的纹理是程序生成的 16x16 占位纹理，计划日后重新绘制。

## 四种材料

| 材料 | 主题 | 形态 | 存储方块 |
| --- | --- | --- | --- |
| Nero合金 | 工业 | 粒、锭、粉、板 | Nero合金块 |
| 星钢 | 太空时代 | 粒、锭、粉、板 | 星钢块 |
| 虚空水晶 | 外星 | 碎片、宝石（“虚空水晶”）、粉 | 虚空水晶块（微弱发光） |
| 等离子玻璃 | 透明 | 碎片 | 等离子玻璃方块 + 玻璃板 |

## 形态与物品 ID

### Nero合金与星钢

两者都是金属，共享相同的四种形态以及一个存储方块。

- 粒
- 锭
- 粉
- 板
- 存储方块（“Nero合金块”／“星钢块”）

### 虚空水晶

它是水晶，因此**没有板**。

- 碎片（`void_crystal_shard`）
- 显示为“虚空水晶”的宝石物品（物品 ID `void_crystal`）
- 粉
- 存储方块（“虚空水晶块”，微弱发光）

### 等离子玻璃

- 显示为“等离子玻璃碎片”的碎片物品（物品 ID `plasma_glass`）
- 透明方块“等离子玻璃”（`plasma_glass_block`）
- 玻璃板“等离子玻璃板”（`plasma_glass_pane`）

## 始终通过标签引用

切勿依赖材料的物品 ID。请通过标签引用材料，以便整合包和其他模组进行替换、调整或扩展：

- 跨模组配方和机器输入／输出使用 `c:` 系列（例如 `c:ingots/nero_alloy`）
- “这是否是我们的材料？”的检查使用 `neroland:materials/<material>`

完整的标签映射参见[标签与数据包](Tags-and-Datapacks.md)。
